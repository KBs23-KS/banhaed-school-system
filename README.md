# Banhaed School System — Professional UI v2

ระบบข้อมูลนักเรียนและบุคลากร โรงเรียนบ้านแฮดศึกษา

## จุดเด่นเวอร์ชันนี้
- ใช้ตราโรงเรียนจริง
- Landing page ใหม่แบบมืออาชีพ
- หน้าเข้าสู่ระบบนักเรียนและครู/บุคลากร
- Responsive สำหรับมือถือ แท็บเล็ต และคอมพิวเตอร์
- เตรียม Firebase client ไว้แล้วผ่าน Environment Variables

## Deploy บน Vercel
1. อัปโหลดไฟล์ทั้งหมดใน ZIP นี้ทับไฟล์ใน repository เดิม
2. Commit ไปที่ branch `main`
3. Vercel จะ Redeploy อัตโนมัติ
4. ตั้ง Firebase Environment Variables ใน Vercel Project Settings
